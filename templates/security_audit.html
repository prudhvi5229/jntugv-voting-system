Security Core Audit Ledger

Active Cryptographic Security Framework Compliance Matrix

🔒 Tri-Node Consensus Engine

Votes are saved into three separate virtual database copies at the same time. If a hacker changes one copy, the other two copies instantly reject the change.

🔒 Salty Ballot Obfuscation

Candidate names are converted into encrypted secret codes before storing. Even the server owner cannot read who voted for whom inside the backend ledger.

🔒 Zero-Knowledge Token Binding

Locks your secret voting token directly to your phone's IP address and browser session. Nobody can steal your token to vote from another computer.

🔒 Forensic Intrusion Lockout

If the system detects a high-level hacking attempt or database modification, it automatically freezes the entire app completely to save data.

🔒 Anti-DDoS Rate Limiting

Blocks hackers or bad automated bots who try to send thousands of rapid requests to crash or slow down the college election server.

🔒 SQLi & XSS Sanitation

Cleans and scans all input fields like Hall Ticket and Passwords. It prevents hackers from injecting harmful script commands into our system.

🔒 Session Hijack Interceptors

If a logged-in student's network IP changes suddenly during the vote, the system recognizes it as a hack and automatically logs them out.

🔒 Immutable Nullifier Cache

Converts each student's ID into a one-time cryptographic lock. Once a student votes, their token is destroyed, making double voting 100% impossible.

🔒 SHA-256 Link Integrity Auto-Check

Every block is digitally glued to the block before it. If a hacker edits an old vote, the cryptographic chain link breaks and triggers a security error.

🔒 Brute-Force IP Lockout

If any user tries to guess a password and enters a wrong password 5 times, the server completely blocks that IP address from trying again.

🔒 Master Override Routing Key

Ensures that only the authorized college administrator can break an emergency forensic freeze and safely reboot the system using a secret key.

🔒 Zero-Cloud Local Privacy

No student photos or election data are uploaded to third-party public clouds. Everything is handled locally via encoded base64 text for total security.
